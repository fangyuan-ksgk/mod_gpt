  The key distinction: abs_loss (how well the model predicts p(a|s)) separates diversity from uncertainty:
  - Zipf experiments: abs_loss 0.87–1.44 — the model spreads tokens around but can't predict which one belongs where. This is pure noise injection.
  - Non-zipf experiments: abs_loss 0.00–0.01 — the model knows exactly what abstract token goes where, it just uses only 1-2 of them.

  Zipf forces diverse marginals without teaching the model which diverse token to use. Increasing alpha_abs alongside zipf should fix this by forcing
  p(a|s) to be sharp even as the marginal is spread.
